---
title: "LegacyPodClaw"
---

LegacyPodClaw is an AI assistant for jailbroken iOS 6 devices. It is a native Objective-C port of [OpenClaw](https://openclaw.ai). Its earlier name was ClawPod.

The code has about 22,000 lines of Objective-C. It has one vendored dependency: [wolfSSL](https://www.wolfssl.com/) 5.9.4 for TLS 1.2. The rest of the code is written for the small memory of iOS 6 hardware.
